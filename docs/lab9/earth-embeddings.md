# Earth embeddings

Earth embeddings are a relatively recent innovation in remote sensing and geospatial AI. They're generated by compressing  satellite and ancillary geospatial layers using large deep learning models trained on huge volumes of data. An Earth embedding provides an information rich signature for a location that can be used as a predictor variable in classification and regression tasks. 

You can read about Earth embeddings in <a href="https://ieeexplore.ieee.org/stamp/stamp.jsp?arnumber=11636001" target="_blank">Klemmer et al., (2026)</a>, <a href="" target="_blank">Stewart et al., (2026)</a> and in this <a href="https://developers.google.com/earth-engine/tutorials/community/satellite-embedding-01-introduction" target="_blank">Google Earth Engine guide to AlphaEarth Satellite Embeddings</a>.

## Regression tasks

The other labs have demonstrated classification tasks - converting image bands into a categorical outcome. However, there are many applications where we need to convert image bands to a continuous numeric outcome. This is a regression task. Work through <a href="https://developers.google.com/earth-engine/tutorials/community/satellite-embedding-04-regression" target="_blank">Regression with Satellite Embedding Dataset</a> in the Google Earth Engine Developer Guide. This will demonstrate how to predict above ground biomass using Google Satellite Embeddings as input predictor variables. **I recommend you add a step to this script to centre the map on the location of the provided `geometry`.**

## Similarity search (bonus activity)

Work through <a href="https://developers.google.com/earth-engine/tutorials/community/satellite-embedding-05-similarity-search" target="_blank">Similarity Search with Satellite Embedding Dataset</a>. This demonstrates similarity search: an approach where you can click on a few features on a map (e.g. of grain silos here) and a similarity search on embeddings is performed to find similar locations. This is a different way of extracting information out of dense satellite archives. Try adapting this workflow to a suburb in Perth and searching for certain geographic features (e.g. car parks, playgrounds).
